# NuBagz Product Logic

## North star

Make crypto onboarding possible without requiring a new user to fund an account first, while keeping reward economics sustainable for NuBagz and accessible to small project creators.

## Core rule

**NuBagz does not pay user rewards from founder capital.** Real-value reward inventory must originate from a project, partner or revenue-generating opportunity before a campaign can promise it.

## Marketplace sides

1. **Earners** contribute attention, learning, creativity, testing, gameplay or other useful participation.
2. **Projects** contribute token inventory and/or economically funded opportunities.
3. **Referrers / discoverers** can receive a configurable share for sourcing genuine participants.
4. **NuBagz** provides trust, campaign structure, reputation, accounting, discovery and settlement infrastructure and receives a configured share.

## Why this is not a launchpad

NuBagz does not exist to raise money for a token launch. Users are not asked to invest in listed projects. A Bag can be created for an existing token, game, protocol, learning experience, creator task or other crypto project. The primary action is **earn through participation**, not **buy a launch allocation**.

## Campaign lifecycle

DRAFT → PENDING → LIVE → COMPLETED / SUSPENDED / REJECTED

A project must be APPROVED before a campaign can be submitted. A campaign must be LIVE before earners can join or complete missions.

## Reputation

BagScore is intentionally separate from wallet wealth. It increases with completed, verified participation. It is intended to become an anti-Sybil and opportunity-quality signal rather than a measure of net worth.
